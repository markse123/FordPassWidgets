# Security policy

## Report a vulnerability privately

Please use [GitHub private vulnerability reporting](https://github.com/markse123/FordPassWidgets/security/advisories/new) for suspected security issues in FordPassWidgets, its installer or its install website. Do not open a public issue containing security-sensitive details.

Include the affected release, the relevant component, the expected and observed behavior, the potential impact and minimal steps to reproduce. Prefer a synthetic example that does not involve a real account or vehicle. You do not need to demonstrate an issue by sending a vehicle command.

Do not include passwords, tokens, VINs, account identifiers, precise locations, unredacted logs, raw vehicle responses or personal screenshots, even in an initial private report. If the issue involves exposed information, describe the type of information without copying its contents. Maintainers can discuss the minimum safe evidence needed in the private report.

## Fixes and disclosure

Report issues against the latest published release where possible. Maintainers assess reports and prepare fixes as capacity permits; this community project does not promise a response or resolution deadline. Coordinate public disclosure through the private report so affected users can receive a fix first.

For ordinary installation problems, incorrect readings or model-support feedback, use the [public issue forms](https://github.com/markse123/FordPassWidgets/issues/new/choose) after removing personal information. See the [contribution guide](docs/CONTRIBUTING.md) for privacy-safe reports and synthetic test fixtures.
